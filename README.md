# SAMMYBOT

Веб-приложение (PWA): дневник питания и инсулина. Пользователь фотографирует блюдо, нейросеть оценивает блюдо, массу порции и углеводы, приложение показывает граммы углеводов, ХЕ и справочную дозу инсулина. История хранится в браузере пользователя.

> **Важно.** Это справочный дневник, а не медицинский инструмент. Расчёты приблизительны, дозу инсулина назначает лечащий врач. Перед публичным запуском проверьте требования к медицинскому ПО в вашей стране.

## Возможности
- Камера на главном экране и одна кнопка «Сделать фото».
- Распознавание блюда (три варианта с вероятностями), оценка массы и углеводов на 100 г; всё можно поправить вручную.
- Справочная доза по вашим коэффициентам, предупреждения о необычных значениях.
- История с фильтрами, редактированием и отметкой «инсулин введён».
- Светлая и тёмная темы, установка на экран телефона, работа страницы офлайн (распознавание требует интернета).

## Структура
```
public/        клиент (index.html, manifest, service worker, иконка)
server.js      статический сервер + прокси к API распознавания, без зависимостей
test/smoke.js  быстрая проверка сервера
Dockerfile, render.yaml, .github/workflows/ci.yml
```

## Запуск локально
Нужен Node 18+ (для `npm run dev` Node 20.6+).
```bash
cp .env.example .env      # впишите ANTHROPIC_API_KEY
npm run dev               # http://localhost:3000
npm test
```
Камера в браузере работает на `localhost` и по HTTPS.

## Публикация
**Render.** Подключите репозиторий (New → Blueprint, подхватит `render.yaml`), задайте `ANTHROPIC_API_KEY`. Получите ссылку вида `https://sammybot.onrender.com`.

**Docker.**
```bash
docker build -t sammybot .
docker run -p 3000:3000 -e ANTHROPIC_API_KEY=... sammybot
```
Подойдут также Railway, Fly.io или VPS с Node.

GitHub Pages не подходит: на нём нет сервера, а ключ API нельзя держать в клиентском коде.

## Приватность и стоимость
- Ключ API хранится только на сервере.
- Фото отправляются на сервер после согласия пользователя и не сохраняются. История, фото записей и настройки лежат в `localStorage` браузера.
- Каждое распознавание платное; в `server.js` лимит 20 запросов в минуту с одного адреса. Для публичного запуска добавьте свои ограничения.

## Известные ограничения
- Масса и углеводы оцениваются по одному фото и могут ошибаться на десятки процентов; вероятности вариантов блюд называет модель, они не калиброваны.
- Встроенная таблица из 25 блюд ориентировочная и служит запасным вариантом.
- Экспорт истории не реализован.
